# Interviews

Personal research toward a device I will build for myself. Not a study, not a company.

People I ask can be in teknik, idrott, or anywhere else that already knows sweat, salt, or sensors. What they say goes here only with permission.

## Before I write anything down

Ask, out loud:

"Can I write down what you just said, for my own notes? You can be anonymous. I will not put your name anywhere if you say no."

If they say no: nothing in this folder. Memory only, and I do not quote them later.

If they say yes: copy `_template.md` to a new file and fill it the same day.

## Anonymity

Default is anonymous. File name is the date plus a role, not a person.

- `2026-10-01-idrott.md`
- `2026-10-01-teknik.md`

Name goes in the file only if they said their name can be written. One line, their words: "Name ok" or "Anonymous".

No audio in the repo. Transcript only. If I record, I ask first, keep the file off GitHub, and delete it when the transcript is done unless they said to keep it.

## What I am listening for

Corrections to `biology.md`. Answers to open lines in `questions.md`. Anything they say I should measure with a scale and a bottle before a sensor.

I write what they said, not what I wished they said. If I add a guess, I mark it `ME:`.
